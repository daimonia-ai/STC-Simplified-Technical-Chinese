# for web dev

适用于网页和应用界面上给用户看的文字：按钮、标签、提示、报错、通知、空状态、页面正文。手机应用和桌面应用的界面文字同样适用。

按“谁看”判断是否属于本场景：存在数据库里、最终显示给用户的文字（通知模板、标签名）属于本场景；服务器日志、代码注释属于 for document。

通用规则（[`for-all.md`](for-all.md)）同样适用。

### W1 不用指代不明的复数人称和第三人称代词

界面文字不得使用这些代词：“你们、他们、她们、它们、咱们、大家、他、她、它”。要说谁，必须写名称。“我们”只可指写这段话的产品方或公司，按 W2 使用。

原因：界面上同时出现用户、用户所在的公司、产品方和其他对象，复数代词指的是哪一群，读者要猜。按钮、提示、报错常常单独出现，第三人称代词找不到所指的词。

- ✗ 你们的账号已开通。
- ✓ 你的账号已开通。
- ✗ 大家分的是同一块蛋糕。
- ✓ 各品牌分的是同一块蛋糕。
- ✗ 当前账号没有它的查看权限。
- ✓ 当前账号没有这份报表的查看权限。

### W2 “你”指读者，“我”“我们”指产品方

面向客户的官网、方案、分享页和产品界面，必须按本条确定人称。“你”只指读者，也就是客户；“我”“我们”只指写这段话的产品方或公司。

标题、按钮和菜单同样适用。不得用“我”“我的”替读者说话；称读者必须用“你”，或省略代词。指代仍不明确时，必须写出名称。

引用用户输入的原话时，可保留原话里的“我”，但必须加引号。英文中的 my、your 同理：不得用 my 替读者说话。

- ✗ 菜单：“我的订单”
- ✓ 菜单：“你的订单”，或只写“订单”
- ✓ 产品方说明：“我们会在 3 个工作日内回复。”
- ✓ 引用用户原话：用户输入了“我想查询订单”。

### W3 按钮以动词开头，用推荐的动作词

按钮文字必须以动词开头，宜不超过 6 个字。动作词宜使用推荐词表里的词，同一个动作全站必须使用同一个词。

说明：推荐词表给删除、移除、清空这类动作词各定了一个意思，见 [`recommended.yaml`](../dictionary/recommended.yaml)。

- ✗ 立即提交审核申请吧
- ✓ 提交审核

### W4 同一个功能在各处同名

同一个功能在导航、标题、按钮、提示和帮助文档里必须使用同一个名称。

- ✗ 导航叫“项目”，按钮写“新建工程”。
- ✓ 导航叫“项目”，按钮写“新建项目”。

### W5 报错说清发生了什么、接下来能做什么

报错必须说清两件事：发生了什么，用户接下来能做什么。报错不得只给错误代码，不得责怪用户。

- ✗ 操作失败（500）。
- ✓ 保存失败：网络连接中断。检查网络后重试。
- ✗ 你输入错了。
- ✓ 请输入 11 位手机号码。

### W6 空状态说明这里会出现什么、怎么开始

空状态必须说明这里会出现什么内容，以及用户怎么开始。

- ✗ 暂无数据。
- ✓ 还没有报告。完成第一次诊断后，报告会出现在这里。

### W7 说明文字讲“是什么、怎么读”，不讲操作

说明文字（悬停提示、信息图标里的文字）必须回答“这是什么、怎么读”。怎么操作必须由控件本身表达，不得写进说明文字。

- ✗ 点击任意一行可以查看明细。这个数字表示提到你的回答占全部回答的比例。
- ✓ 提到你的回答占全部回答的比例。

### W8 一句界面文字写成一个完整的字符串

一句界面文字必须写成一个完整的字符串模板，不得拼接句子片段。

原因：拼接出来的句子，检查和翻译时都拿不到整句；换成其他语言时语序也会出错。

- ✗ `'已选择' + count + '个文件'`
- ✓ `'已选择 {count} 个文件'`

### W9 页面文字服务当前用户

界面上的每句话必须说明当前对象、结果、操作或必要边界。制作标签、验收结论和设计取舍必须放在开发记录里。

审阅必须覆盖实际渲染的标题、正文、按钮、提示、图注和角标。按 G20 判断每句话是否必要，不能只检查术语和标点。

- ✗ 在正式产品首页写“当前页面仅用于展示功能布局”。
- ✓ 删除该句，用实际功能和操作说明组织页面。
- ✓ 示例数据，仅用于说明报表格式。（读者需要区分示例与真实数据。）

### W10 同一处界面统一称呼读者

一个组件、一张卡片、一个弹窗，或标题及下方的说明，属于同一处界面。同一处里，指读者必须只用一种叫法。

不得同时用“我的……”和“你的……”指同一个人。标题、按钮、菜单和说明必须按 W2 称读者为“你”。说明文字可以不用代词。

- ✗ 标题“发给我的 Agent”，说明“交给你的 Agent 来读”
- ✓ 标题“发给你的 Agent”，说明“交给你常用的 Agent 来读”
- ✗ 标题“我的订单”，空状态“你还没有下过单”
- ✓ 标题“你的订单”，空状态“还没有订单”
