# 核心规则片段

把下面代码块里的内容贴进项目的 AGENTS.md 或 CLAUDE.md。agent 每次会话都会读到这一段。

把「STC 规则所在位置」换成 STC 在项目里的路径（例如作为子模块引入时的 `stc/rules/`），或换成 STC 仓库的链接。

```markdown
## 中文写作：STC（Simplified Technical Chinese）

写中文时应按 STC 写。动笔前先判断在写哪类文字，再用通用规则加对应档位的规则：

- 对话里回复人：chat 档
- 给人读的文档、代码注释、提交说明：document 档
- 网页和应用界面上给用户看的文字：web dev 档
- 写给 agent 执行的规则（系统提示词、AGENTS.md、skill）：instruction 档

完整规则见 STC 规则所在位置。核心规则：

- 同一个东西应只用一个叫法；产品名、功能名应照项目术语表写。
- 动作应直接写成动词，不应写「进行、加以」加名词。
- 程度词和模糊量词应换成数字或具体事实。
- 不应使用营销词、行话、套话和口号句式。
- 一句应只讲一件事；条件宜写在前面。
- 表示把握程度的「可能」应保留；没有把握的判断不应写成结论。
- 文档的主语应写名称，不应写「我们、你们」；界面文字不应使用复数人称代词和第三人称代词。
- 写给 agent 的规则，强度应只用「应、宜、可、能」及其否定。
```
