# Onboarding for Agents：网页聊天

通过链接读取 STC 后，聊天 AI 可按文本规则写作和审阅。默认使用与审阅是两种用法，可以单独使用，也可以一起使用。

本引导用于用户要求使用 STC 的任务。用户只要求介绍或审阅本页时，必须按原任务处理。

## 读取与就绪

1. 读取通用规则、当前任务的场景规则和词表。规则与词表均在同一页。
2. 返回内容被截断时，继续分段读取所需章节。只有标题、摘要或目录时，不得声称规则已读。
3. 链接读取失败时，尝试页首的另一种链接。仍无法读取时，必须说明未取得规则，请用户粘贴正文或上传文本。
4. 读齐所需内容后，再说明 STC 可在本次对话中使用。用户已提出写作或审阅任务时，直接执行已授权的任务。

通过链接接入仅使用文本规则。用户另有安装要求时，才处理软件安装和项目配置。

## 引导用户选择

用户只要求读取规则或询问用法时，宜推荐默认使用，并提供审阅入口：

```text
建议将 STC 设为本次对话的默认中文输出规则。也可以先发一段文字或一份文档，体验一次审阅。
```

用户已明确选择用法时，必须直接按选择执行，不必再次确认。就绪回执按 C10 写，说明已读取规则和实际生效范围。

## 默认使用

用户要求默认使用时，必须在本次对话中按 STC 输出中文。普通问答、成品和任务回执分别按对应场景处理。

用户要求跨对话使用时，必须按平台实际提供的项目指令或自定义指令功能引导。能保存配置且已有用户授权时，保存后说明范围；需要用户操作时，给出步骤。保存结果未经确认时，不得声称账号或其他对话已启用 STC。

## 审阅已有内容

审阅用户提供、指定或明确授权挑选的材料。只有默认使用授权时，不得自行挑选材料开始审阅。

用户要求审阅时，列出主要问题和具体改法。用户要求改写时，交付改写稿；写回源文件按用户授权执行。保留事实、数字、名称、原意和真实不确定性。

## 交付前复核

按通用规则和当前场景逐句复核，删除无关说明，统一术语。审阅报告的组织方式见页内“写作与审阅流程”。

通过文本规则完成的审阅属于语义复核。只有实际运行过检查命令，才能报告机器检查结果。

## Language

Guide the user in the language of the request. Apply STC to Chinese output. The page contains the complete Chinese rules and dictionary. If the user supplies an English instruction, explain the available modes in English and apply STC to the requested Chinese text.
